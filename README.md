this is a cart system project that was built using react
Recently I built a similar project using javascript and it was challenging that's why I decided to remake it with different UI using react
this project gave me real hands-on experience and I had the opportunity to learn new stuff in react and enhance my skills

in this project you can add an item to the menu after typing its description and adding an image by yourself!
you can then add these items to the cart if you want and calculate the total price and you may remove an item if you wish!
